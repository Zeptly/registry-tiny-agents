# Cross-Registry Reconciliation Required

This registry is a **candidate** architecture. The following are **unresolved** and must be reconciled into a common
Zeptly Registry Protocol (with the Skills, Execution Agent and QB registries) before any registry PR is merged:

1. Universal Zeptly registry **ID format**.
2. **Cross-registry reference/address** format.
3. **Version-directory convention** across all registries.
4. **Candidate representation** across all registries.
5. Common **maturity / origin / lifecycle vocabulary**.
6. **Evidence-reference protocol** (a common Zeptly Evidence Protocol).
7. **Index format and publication**.
8. **Provenance schema**.
9. **Digest / sealing convention**.
10. **SemVer change classification**.
11. Shared **capability / tool / gateway namespaces**.
12. Shared **evaluation-result format**.
